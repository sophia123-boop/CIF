# CIF Junior


## Introduction
CIF or Coding Is Fun is a public program to help young coders to learn programming via various fun projects, through different coding languages and programs like:

- Python
- Markdown
- Mermaid
- C++
- Html
- Javascrip
- CSS

And much more.

We cover six prjects via 20 units.
